# Code of Conduct – FitMate

Our goal is to keep FitMate a welcoming, respectful, and collaborative open-source project.

## Expected Behavior
- Be polite and respectful to all contributors.
- Consider different perspectives and constructive feedback.
- Focus on the issue, not the person.
- Use inclusive and professional language.

## Unacceptable Behavior
- Harassment, threats, or personal attacks.
- Discriminatory or offensive comments.
- Publishing someone's private information without consent.
- Intentional disruption of discussions or collaboration.

## Reporting an Issue

If you experience or witness behavior that violates this code of conduct, please report it to the project maintainer using a private message on GitHub. Include a description of the incident and any relevant links.

Maintainers are responsible for reviewing reports and taking appropriate action.
